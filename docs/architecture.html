Factory Inventory Management System

A full-stack demo. A Vue 3 single-page app talks to a Python FastAPI service. The service serves mock data that it loads from JSON files into memory at startup. There is no database, so every request filters the in-memory lists.

Request data flow

Example: the user picks a warehouse and Q3-2025 on the Dashboard.

  1. FilterBar writes to module-level refs in useFilters.js. Those refs are a singleton, so every view sees the same filter state.
  2. The view watches the filters and calls getCurrentFilters(), which maps Location to warehouse and Period to month.
  3. api.js adds each filter that isn't "all" as a query param, e.g. GET /api/dashboard/summary?warehouse=Tokyo&month=Q3-2025.
  4. FastAPI runs apply_filters() (exact warehouse match; category and status matched case-insensitively). Then filter_by_month() expands quarters with QUARTER_MAP and substring-matches order_date.
  5. The result is checked against a Pydantic response_model and returned as JSON.
  6. The view stores the response in a ref. Computed properties then recalculate the KPIs, tables and SVG charts.

Observations

Missing backend routes. api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders (POST, GET by backlog item), but main.py doesn't define them. Those calls will return 404.
Unrouted view. views/Backlog.vue exists, but main.js has no route for it and the nav doesn't link to it.
Hard-coded quarters. QUARTER_MAP only covers 2025. The month filter uses substring matching on order_date.
Mock auth. useAuth returns a fixed, locale-aware demo user. There is no real authentication.
